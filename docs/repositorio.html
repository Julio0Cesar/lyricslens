LyricsLens

Repositório de pacotes — atualizações pelo gerenciador da sua distribuição.

Adicionando este repositório, o lyricslens passa a ser atualizado junto com o resto do sistema, sem baixar arquivo à mão a cada versão. Se preferir instalar sem repositório, os pacotes continuam em Releases.

Debian, Ubuntu, Mint

curl -fsSL https://julio0cesar.github.io/lyricslens/lyricslens.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/lyricslens.gpg

echo "deb [signed-by=/usr/share/keyrings/lyricslens.gpg] https://julio0cesar.github.io/lyricslens/apt ./" \
  | sudo tee /etc/apt/sources.list.d/lyricslens.list

sudo apt update
sudo apt install lyricslens

O signed-by restringe a chave a este repositório. Sem ele a chave passaria a valer para qualquer repositório configurado na máquina, o que é bem mais poder do que instalar um app precisa.

Fedora, openSUSE, RHEL

sudo rpm --import https://julio0cesar.github.io/lyricslens/lyricslens.asc

sudo tee /etc/yum.repos.d/lyricslens.repo <<'EOF'
[lyricslens]
name=LyricsLens
baseurl=https://julio0cesar.github.io/lyricslens/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://julio0cesar.github.io/lyricslens/lyricslens.asc
EOF

sudo dnf install lyricslens

gpgcheck confere a assinatura de cada pacote; repo_gpgcheck confere a do índice. Os dois estão ligados de propósito — o primeiro sem o segundo deixaria alguém trocar a lista de pacotes disponíveis.

Conferindo a chave

A impressão digital da chave que assina este repositório: 

F442 087C 732F 68D2 752E  85AC FDB1 007B 2804 89EA

Depois de importar, compare com o que o seu sistema registrou: 

gpg --show-keys /usr/share/keyrings/lyricslens.gpg   # Debian
rpm -qi gpg-pubkey-280489ea                          # Fedora

Removendo

sudo rm /etc/apt/sources.list.d/lyricslens.list /usr/share/keyrings/lyricslens.gpg   # Debian
sudo rm /etc/yum.repos.d/lyricslens.repo                                            # Fedora

O que fica aqui

O repositório oferece as dez versões mais recentes. Versões anteriores continuam disponíveis como anexo das releases, que é onde elas sempre estiveram.

Arquiteturas: x86_64 apenas.
